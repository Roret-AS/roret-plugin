# Rorets markedsplass for Claude

Her ligger pluginen `roret`, som kobler Claude til regnskapet ditt i
**Roret** eller **Roret for Odoo** og gir Claude norske arbeidsflyter for
bilag, bank, MVA, purring, lønn, salg, kundeservice, styrearbeid og flytting
fra et annet regnskapssystem.

Hva pluginen gjør, hva den trenger og hvordan du installerer den, står i
guiden: [roret/README.md](roret/README.md).

**Claude Code:**

```
claude plugin marketplace add Roret-AS/roret-plugin
claude plugin install roret@roret
```

Spørsmål: support@roret.no.
